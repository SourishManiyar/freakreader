# Bibliography oracle: reference lists, entries, fields and citations known from the DVI

This directory measures the bibliography analysis (`pdfcraft_render::text::page_layout::bib`, and the
reference graph `pdfcraft_engine::references` builds on it): synthetic papers whose LaTeX we wrote and
compiled ourselves with pdfTeX and BibTeX, citing an invented library, so which glyphs make up each
entry of the reference list, what its printed label is, which glyphs of the text make up each
citation and which entry each one names are TeX's own answer, and what each entry's fields are is the
`.bib` file's. It extends the layout oracle (`../../layout/oracle/README.md`) and uses its truth as is.

## Files

| File | What it is |
|---|---|
| `library.bib` | 70 invented entries: articles, books, chapters and proceedings, preprints with arXiv ids, theses, reports; one to seven authors and lists cut with `and others`; accented, hyphenated and `van der` names; math in titles; one author list with three papers in one year and one with two (`2020a`–`2020c`); DOIs (the `10.5555` test prefix), URLs (`example.org`), MR and Zbl numbers outside the ranges in use. Written for this repository: no real paper's title or authors. |
| `papers.toml` | The paper list: class, options, geometry, BibTeX style or a list written by hand, natbib, hyperref, how many entries, a seed, and the body as directives (`cite ? at=Theorem_3.1`, `citet s61`, `range a01 a04`, `trap interval`, …). Papers whose id starts `ho_` are held out. |
| `pdfcraftlayout.sty` | The layout oracle's bracket package, as compiled. |
| `pdfcraftbib.sty` | This oracle's bracket package (`pdfcraft_oracle::tex::bib::package`), as compiled. |
| `<paper>.tex`, `<paper>.pdf`, `<paper>.bbl` | Each paper, generated from `papers.toml`, and the list BibTeX made for it. Prose comes from the layout oracle's seeded word lists (`xtask/src/layout_oracle.rs`). |
| `truth.tsv` | The layout truth of the papers, and their entries (key, order, printed label, fields as printed, glyphs), citations (form, key, glyphs) and traps. Format: `pdfcraft_oracle::tex::bib::BibTruth`. |
| `holdout.lock` | Fingerprints of the held-out papers (see below). |

All but `library.bib`, `papers.toml` and this README are generated by `cargo xtask bib-oracle generate`
and must not be edited.

## How the truth is made

The layout oracle's brackets stay; this oracle adds `\special{pdfcraft:layout:x:…}`, which the layout
truth passes over:

- **Entries.** The kernel's `\@bibitem` and `\@lbibitem` (natbib's and hyperref's, once loaded) are
  wrapped at the start of the document to say which key comes next; nothing is typeset there. The
  paragraph hook then puts `x:bib:begin:KEY` at the start of the paragraph the `\bibitem` opens,
  before the label box that `\everypar` puts there, so the label is the entry's, and `x:bib:end` at
  that paragraph's end. An entry's glyphs are those between, in text blocks of the layout truth (not
  a running head shipped meanwhile), across columns and pages. The heading is the paragraph after
  `\begin{thebibliography}` (`x:bib:head`).
- **Citations.** For `\cite`, the kernel's `\@cite@ofmt` (the box of each key's label, not the
  locator of `\cite[Thm.~2]{k}`) is wrapped in `x:cite:begin:N:KEY` and `x:cite:end`; for natbib,
  `\hyper@natlinkstart`, `\hyper@natlinkend` and `\hyper@natlinkbreak`, where hyperref puts its
  links: `Smith and Jones` and `2020` of `Smith and Jones (2020)`, the parentheses outside.
  `N` counts the citations, one per key, so the generator knows what each is. A range
  (`\pdfcraftrange{a}{b}`, `[1–4]`) brackets its two numbers; the keys between are citations with no
  glyphs (form `range_inner`). A citation typed by hand (`\pdfcrafthand{KEY}{Okafor (2020a)}`)
  brackets its text.
- **Traps** (`\pdfcrafttrap{ID}…\pdfcrafttrapend`) bracket text that looks like a citation and is
  none: `$[0,1]$`, `$[a,b]$`, `$[1,3]$`, `$[x]$`, `$[x,y]$`, `$[2]_q$`, `Section~[3]` (a number that is
  a label of the list), a display `[a,b] \subset [0,1]`, and list items labelled `[2]`.
- **Labels** are the `.bbl`'s: the entry's number for numeric styles (BibTeX's order), the optional
  argument for `alpha`, none for author-year lists.
- **Fields** are the `.bib` file's, each only where the typeset entry shows it (its value, after the
  normalisation below, is in the `.bbl` entry's text): a style that prints no DOI has none to find,
  and an author list is the family names the entry prints. The year carries the suffix the style
  adds (`2020a`). Lists written by hand record what they print.

Each PDF is compiled again with both bracket packages reduced to source macros without specials and
must come out **byte-identical** (`generate` fails otherwise). Generation runs pdfTeX to DVI, BibTeX,
pdfTeX twice more to DVI (labels), and three times to PDF in each directory (the `.bbl` copied), with
`SOURCE_DATE_EPOCH=1700000000` and `FORCE_SOURCE_DATE=1`, without shell escape; `generate --check`
regenerates into a temporary directory and requires every file byte-identical. Only AMS Type 1 fonts
may be embedded (Computer Modern, OFL-1.1, `../../math/OFL-AMSFonts.txt`), and no citation may be
left undefined. `the_pdfs_hold_exactly_what_the_dvi_lists` checks that the PDF draws every glyph the
DVI lists, at its place, and nothing else.

**Linked papers.** The papers with `hyperref = true` carry no DVI truth (hyperref's DVI driver places
some glyphs apart from where its PDF driver does). They are checked against their own `cite.KEY`
links instead: every citation link must have a citation read under it whose entry holds the link's
destination. With the brackets reduced to nothing they must draw the same glyphs within 0.2 pt.

**Normalisation** (`pdfcraft_oracle::tex::bib::fold`): TeX accents and the accents of Unicode letters
dropped to the base letter (`{\"u}`, `ü` → `u`; `\o`, `ø` → `o`), braces, `$`, `^`, `_` dropped, `~` a
space, `--` and Unicode dashes `-`, lower case, whitespace collapsed. Authors compare as the set of
family names; a title by its tokens (F1 ≥ 0.8); a venue by its tokens (F1 ≥ 0.5); a DOI, arXiv id,
URL, MR and Zbl number without spaces and a `doi:`, `arXiv:`, `MR`, `Zbl` prefix; the rest exactly.

### Held-out papers

The `ho_` papers were written on 2026-11-18 before any of the analysis existed, and frozen before it
was scored: `holdout.lock` holds the SHA-256 of each paper's source, PDF and truth rows, and
`cargo xtask bib-oracle generate` (with or without `--check`) fails if any of them would change.
`--freeze` only adds papers. While the analysis was written, only their rates per kind were read
(`cargo xtask bib-oracle report`), never a single failure (`--failures` lists development papers
only). To change a held-out paper, move it to development under a new id and write a new one.

The first held-out rates (read once the analysis passed the development papers) were low for two
kinds the development set did not have: a two-column `alpha` list (half the entries split wrong, two
wrong links) and natbib's author-year citations in `amsart` (one of sixteen found). Their failures
were not read. Three development papers of those kinds were added instead (`art10_alpha2col`,
`ams12_plainnat_ay`, `art10_handbr`, marked "added" above) and the analysis was debugged on them;
`ho_art12_unsrt2col` was written at the same time, before those changes, so that a third of the
papers stay held out. Adding papers showed that citation ids in `truth.tsv` were numbered across the
whole file, so a new paper renumbered every later paper's rows; they are now numbered within each
paper. That one change rewrote the truth-row fingerprints in `holdout.lock`; the source and PDF
fingerprints of every held-out paper are unchanged (the lock's history shows it).

## Scoring

- **Region:** a list found where there is one (and none where there is none); the found region's
  glyphs against the truth's (heading and entries), recall and precision.
- **Entries** (glyph sets): a found entry is the *detection* of a truth entry at F1 ≥ 0.5 (one to
  one, best first); its *boundary* is right at F1 ≥ **0.95**. Spurious: found ones that stand for none.
- **Labels:** of detected entries with a printed label, right, wrong, missing; a label where none is
  printed.
- **Fields:** per field, of detected entries, right, **wrong**, missing, and **invented** (found where
  the entry prints none): precision and recall.
- **Citations** (clickable glyphs): matched at F1 ≥ 0.8. Recall over truth citations, precision over
  found ones; traps hit.
- **Resolution:** of the matched citations, the right entry, a **wrong entry**, none; the keys inside
  a range cited right or wrongly. *Wrong links* are wrong entries plus wrong range keys plus links
  from found citations that stand for none; they matter most and are reported first.

Everything is reported for development and held-out papers apart, per BibTeX style, per citation
mode, and per class, columns and size.

```sh
cargo xtask bib-oracle report                       # the analysis, dev and holdout apart
cargo xtask bib-oracle report --analyser all        # with the deliberately broken analysers
cargo xtask bib-oracle report --dev                 # development papers alone (while changing the code)
cargo xtask bib-oracle report --failures            # the development papers' failures, one by one
cargo xtask bib-oracle generate --check             # regenerate (needs TeX Live and BibTeX), require identical bytes
cargo xtask bib-oracle generate --freeze            # add new held-out papers to holdout.lock
cargo xtask bib-oracle test                         # the oracle's tests
```

Three broken analysers prove the harness discriminates (`broken_analysers_score_badly`): one that
splits the list at every line, one that links every `[n]` it sees to entry `n`, one that resolves an
author-year citation by its first author alone, whatever the year.
