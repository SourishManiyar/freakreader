# The symbols the table knows, written for this repository from the Unicode charts and from
# what LaTeX documentation says each command is for: no table is copied from a package, a font
# map or another product. `cargo xtask math-symbols generate` typesets each line alone with TeX,
# reads the font and character code of the glyph(s) TeX sets from the DVI, and writes `table.tsv`
# next to this file; nothing here says which code a symbol has.
#
# A line is   LATEX  ENV  UNICODE  CLASS  KIND  [FLAGS]
#   LATEX    the command as written in a formula; `~` stands for a space in a template.
#   ENV      i typeset inline (text style), d displayed.
#   UNICODE  hex code points joined by `+`, or `-` for none.
#   CLASS    ord op bin rel open close punct large inner: the TeX math class.
#   KIND     sym latin greek digit: what the glyph is when it is a letter.
#   FLAGS    `-` or comma-separated: `var=GROUP:RANK` a size variant of GROUP (RANK 0 is the smallest),
#            `acc` a math accent, `fn` a function name.
# A line that sets more than one glyph is a compound (`\ne` is a slash drawn over `=`).
# `@delim`, `@radical`, `@wide`, `@brace`, `@accent` and `@alphabet` lines are read as the generator says.
